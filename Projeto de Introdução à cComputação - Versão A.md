# Projeto IC Git
O projeto tem como objetivo a introdução ao git e commit.

## Funcionalidades 
Conectado ao repositório remoto.

Modo de edição público.

## O que aprendi
Ao longo da aula, aprendi a utilizar novos comandos git para criar repositórios locais, alterando-os e realizando commits.
Para além disso, realizei o merge entre o repositório local e remoto no GitHub.
